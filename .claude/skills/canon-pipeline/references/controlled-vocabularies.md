## Canonical verse reference abbreviations (use per language)

All inline verse references in text fields **must** use the canonical abbreviation for their language. The viewer's detection regex requires this — unlisted forms will not generate links.

**Format rules (all languages):**
- Range: en-dash `–` → `Nm 6:24–26`
- Multi-verse: comma → `Lc 24:27,44`
- Chapter-only / chapter-range: omit colon+verse when citing a whole chapter or span → `Nm 16`, `Nm 22–24`
- `ref` key fields (language-neutral): always use the **ES** abbreviation
- Every reference in a semicolon list must be fully qualified — never omit the book prefix after `;` → `Nm 1; Nm 26`, not `Nm 1; 26`
